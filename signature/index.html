Installing it

  1. Apple Mail (Mac): Settings, Signatures, add one, then paste the HTML version copied from this page.
  2. iPhone Mail: Settings, Apps, Mail, Signature. iOS keeps only simple formatting there, so check it on the phone.
  3. Gmail web: Settings, See all settings, Signature, then paste the HTML version copied from this page.
  4. Outlook web: Settings, Mail, Compose and reply, Email signature, then paste the HTML version.
  5. Where a client takes plain text only, use the plain-text version.
